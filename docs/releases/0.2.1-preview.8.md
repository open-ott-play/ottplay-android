# Android 0.2.1 preview, build 8

This maintenance candidate advances the preview version code from 7 to 8.
Dependency updates include DataStore 1.3.0 and Kotlin serialization 1.12.0;
coroutines remains on the published 1.11.0 version. The deterministic JVM
parser checks use the exact serialization runtime JAR hashes.

The build toolchain uses Gradle 9.8.2, with updated pinned CI actions and
coherent CodeQL components. Application identity and signing configuration
are unchanged, so the preview retains its existing update path.

Publication requires successful unit tests, lint, APK builds and the existing
phone API35 and Android TV API36 emulator tests for the exact source commit.
The normal signed-preview workflow produces the APK/AAB and checksum evidence.
Physical device acceptance has not been performed for this candidate.

This preview does not promote the previous stable release, publish to Google
Play, or change an installed application automatically.
