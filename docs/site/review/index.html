OTT-play Native: user-initiated media playback

Recording of the 0.2.1 release build on an Android 15 phone emulator, 13 September 2026. The user opens the app, selects the original bundled demo, plays it, returns Home into picture-in-picture and pauses using Android media controls. The eight-second demo has silent audio.

Current app language and review steps

The current app follows Android language preferences, with English as its fallback. All 20 languages offered by OTT-play FOSS are included offline. Open More / Settings → Language to choose English for the steps below, or choose System default to follow Android again. Language names are shown in their own languages.

  1. On a fresh installation, choose Try the demo. No account or network is needed.
  2. Open Test pattern · 8 seconds and use touch controls or the TV remote to play the bundled silent test video.
  3. For an existing setup, open More / Settings and choose Add a demo source.
  4. On a supported phone, Home can open picture-in-picture. On Android TV, Home pauses playback and video PiP is unavailable.
