# Android 0.2.1 preview, build 9

This candidate includes the verified Core 0.1.4 provenance manifest merged
after preview build 8. The vendored JVM bytecode, application behavior,
package ID and signing configuration are unchanged by that manifest update.
The version code advances to 9 so the final source can be published without
moving a tag or replacing build 8's signed files.

Publication requires the existing unit, lint, APK, phone API35 and Android TV
API36 emulator checks for this exact source, followed by the normal signed
APK/AAB workflow. Physical device acceptance is not part of this delivery.

After those checks and artifact verification, the existing stable workflow
can promote these same signed bytes while the source remains current. The
historical preview tag and Android package identity are retained. This does
not submit to Google Play or automatically update an installed application.
