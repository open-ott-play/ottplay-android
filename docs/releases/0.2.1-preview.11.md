# Android 0.2.1 preview, build 11

This maintenance candidate aligns OkHttp, its TLS/test companions and the
checked parser-fuzz dependency catalog at 5.5.1. The Gradle update is covered
by the normal Android unit, lint and package checks. Future OkHttp updates
are grouped so the network stack and its test dependencies move together.

The version code advances to 11. The existing preview application ID and
signing identity are retained, allowing the same signed APK to update the
installed preview. This is not a separate production app or Google Play
submission.

Publication requires the exact-source host, phone API35 and Android TV API36
emulator matrix plus signed APK/AAB verification. Stable promotion reuses
those exact signed files. No physical-device acceptance is asserted.
